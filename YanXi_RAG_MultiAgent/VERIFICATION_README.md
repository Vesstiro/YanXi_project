陌生来电响铃前核验：本地桌面模拟

**如何打开**

关闭旧的言犀窗口后，重新运行桌面版。这个功能不需要配置 API Key，也没有新增第三方 Python 依赖。

```powershell
Set-Location "D:\YanXi_project\YanXi_RAG_MultiAgent"
.\.venv\Scripts\python.exe desktop.py
```

左侧新增两个按钮：“核验资料与题数”和“模拟响铃前核验”。现有文字、音频分析仍从原来的输入队列使用；该队列会按原设置调用 Qwen，不属于本地核验流程。请不要把核验资料手动粘贴进原分析队列。

**先设置机主资料**

1. 点击“核验资料与题数”。
2. 选择 3、5 或 7 题。
3. 选择当前事项类别。第一版维护一个当前事项，提供日常联系、工作业务、预约服务、配送联系、其他事项五类。
4. 可填写事项有效期，格式为 YYYY-MM-DD，当天仍有效；留空表示长期有效。
5. 填写以下表格中的资料，并勾选允许用于核验的字段。未授权字段的答案不会保存；取消勾选并保存会移除该字段原先的答案。
6. 别称用 `|` 分隔。例如 `言老师 | 小言`。最多 8 个别称，每个最多 160 个字符。
7. 点击“保存并关闭”。有效且已授权的题目总数必须达到选定题数，系统不会重复问题来凑数。

| 资料 | 实际提问 | 适用范围 |
| --- | --- | --- |
| 常用称呼 | 请问您要联系的人怎么称呼？ | 通用 |
| 单位 / 学校 | 您要联系的人所在的单位或学校是哪里？ | 通用 |
| 部门 / 业务领域 | 这次联系涉及哪个部门或业务方向？ | 通用 |
| 当前联系事项 | 请简要说明这次联系的具体事项。 | 当前事项 |
| 事项关联机构 | 您代表或关联的机构叫什么？ | 当前事项 |
| 已约定的时间 | 如果此前约过时间，请说明约定的日期或时段。 | 当前事项 |
| 自定义核验事项 | 默认询问双方预先约定的项目代称，可改成自己的问题 | 当前事项 |

问题文字本身会向来电者显示，请不要把答案写进自定义问题中。不要填写身份证号、密码、验证码或完整家庭住址。

标准答案默认隐藏。机主可勾选“机主查看答案”编辑自己的预留资料，这不包含任何来电者的原始回答。

**建议先用虚构资料试一次**

为了验证软件流程，不必先填写真实个人信息。可选择“工作业务”、5 题，授权并填写下面全部 7 项：

| 资料 | 示例 |
| --- | --- |
| 称呼 | 小言 \| 言老师 |
| 单位 | 示例大学 |
| 部门 | 计算机学院 |
| 事项 | 校园讲座预约 |
| 关联机构 | 示例活动中心 |
| 约定时间 | 周三下午 |
| 自定义问题答案 | 青竹计划 |

保存后点击“模拟响铃前核验”，号码留空或填写未登记号码，来电事项选“工作业务”。

系统会随机选择 5 个不同问题。填写表格对应的简短答案即可验证匹配；也可以故意答错一题、跳过一题，检查最终汇总。不同次数可能选到不同问题，顺序也可能变化。有当前事项可用时，题组至少包含一道事项问题。

**来电者如何回答**

- 本版是文字问答，没有调用麦克风、语音识别、Edge TTS 或任何在线模型。
- 每题填写答案后点击“提交，继续下一题”，也可按 Enter。
- 不知道时点击“不知道 / 跳过”。空回答，以及“不知道、不清楚、不适用、无法回答、拒绝回答、没听清”，都记为无法核对。
- 每题最多等待 120 秒；超时或点击“提前结束，提醒机主”，保留汇总并显示核验未完成。
- 关闭正在核验的问答窗口，同样按提前结束处理。尚未开始时关闭则直接退出模拟。
- 不展示逐题正确与否，不向来电者显示标准答案，也不提供重试当前题的答案反馈。

匹配规则是本地精确比较：忽略大小写、空白、标点和全半角差异，并接受机主明确设置的别称。**不做模糊或语义匹配**。请用简短名称或约定格式回答；完整长句即使含有正确关键词，也可能被判不匹配。日期等自由表达需在别称中明确设置。识别到“不匹配”仅说明文字与预留资料不符。

只有类别匹配且未过期的事项问题可使用；通用资料始终可用。例如设置 7 题但来电类别不同，最多只有 3 个通用问题可用，系统会提示无法核验，不会换用其他类别的私人资料、凑题或自动判定诈骗。

**哪些号码跳过问答**

- 机主手动登记了备注姓名的联系人，或手动白名单：跳过问答，提示身份仍未得到认证。
- 手动黑名单：跳过问答，说明由既有名单策略处理。此模拟页不会操作真实电话，也不覆盖原分析程序的黑名单规则。
- 陌生号码、隐藏号码：进入核验。
- 仅有来电历史或较高历史信任分的号码仍进入核验；不会因为打过电话就自动当成熟人。

联系人设置沿用“机主与号码管理”，核验模块只读取名单，不修改号码评分、不新增来电历史。

**机主提示页**

问答完成或提前结束后，才进入“模拟响铃 · 机主接听提示”。窗口尝试播放一次系统提示音；能否听到取决于系统提示音设置。提示页显示：

提示页使用浅色圆角卡片、准确率环形图、覆盖率进度条和彩色计数标签。回答不符时显示红色感叹号，核对信息较一致时显示绿色笑脸，资料不足或核验未完成时使用中性表情。这些图案表达核验状态，不表示身份已通过认证。较小窗口中卡片可滚动，接听、转留言和拒接按钮始终保留在底部。

- 设置题数、已提交数；
- 匹配项数、不匹配项数、无法核对或未回答项数；
- 可核对回答准确率；
- 核对覆盖率；
- 进一步核实的建议。

准确率 = 匹配项数 /（匹配项数 + 不匹配项数）。

覆盖率 =（匹配项数 + 不匹配项数）/ 设置题数。

例如 5 题中匹配 3 项、不匹配 1 项、跳过 1 项：准确率为 75%，覆盖率为 80%。全部跳过则准确率显示“暂无法计算”，不能显示成 0% 的身份可信概率。

机主只看到汇总，不会看到题目、原始回答、逐题对错或标准答案。核验准确率不是合法概率，也不是诈骗概率。不了解资料、拒绝回答和超时都不直接认定为欺骗。

“接听 / 转留言 / 拒接（模拟）”只记录当前窗口中的选择，不执行真实电话操作，不触发 Qwen，不把问答接入原来电队列。关闭后这次汇总不再保留。

**隐私边界**

- 预留资料整体用 Windows 当前用户范围的 DPAPI 加密，保存在 `data/verification/vault.json`。没有明文后备文件或单独保存的解密密钥。
- 修改资料采用临时密文文件后原子替换；无法解密、格式损坏时不会静默覆盖原文件。
- Windows 当前账户下的其他程序、管理员或已被控制的主机仍可能访问运行时数据。这是本地存储保护，不是对同账户的访问身份认证。
- 用户输入的回答立即在本地匹配，模块不保留原始回答历史，不写日志或数据库、不主动复制到剪贴板、不导出、不进入云端模型或向量库。输入框在每题后及关闭时清空；Python/Tk 无法承诺进程内存或系统交换区的密码学安全擦除。
- 已完成、提前结束或超时后清除该会话持有的标准答案引用，只保留计数供提示页使用。
- 本模块没有网络、在线语音或电话平台调用，因此这段模拟问答不会主动发送给运营商、Qwen 或其他客户。原有业务分析的联网行为维持原设置。
- 同一电脑上的来电者 / 机主视角仅用于角色模拟，不能阻止能控制该电脑的人切换角色、截屏或调试进程。
- 当前不是 MPC。若未来接入普通电话，来电者口述的回答会经过电话网络；本地加密不能让运营商无法接触电话语音。真正的 MPC 和加密来电端协议需另行设计。
- 主动删除资料可在设置页点击“删除本机核验资料”并确认。删除只移除当前资料文件，不承诺擦除磁盘、系统备份或交换区中的历史副本。

**开发和验证**

核心模块位于 `src/verification/core.py`；界面位于 `src/desktop/verification_dialog.py`。主界面仅新增两个独立入口，不向 `Job`、`DesktopService`、评测数据或结果导出添加私人核验字段。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest tests.test_verification -v
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p "test_*.py"
.\.venv\Scripts\python.exe -X utf8 -m tests.verification_ui_check
```

DPAPI 测试需在正常 Windows 用户环境运行；不提供用户加密配置的隔离沙箱可能拒绝加解密，这不能通过退回明文存储绕过。

回归覆盖 3/5/7 题、别称规范化、未知项分母、覆盖率、取消与超时、事项有效期和类别、联系人跳过、真实 DPAPI 密文读写与损坏保护。独立界面验收使用虚构资料，禁止 Python 网络连接，检查问答结束前不响铃、汇总不含原始资料、底部按钮在较小窗口中仍可见，以及不生成旧队列和通话记录。
